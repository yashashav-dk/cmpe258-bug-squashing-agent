Autonomous Bug-Squashing Agent: Comprehensive Benchmark Report

CMPE 258 — Spring 2026  |  May 7, 2026  |  Internal Dataset: 52 synthetic cases  |  OSS Repo: pallets/click @ 052c006

Abstract. We evaluate an autonomous Planner→Executor→Critic (PEC) agent on two complementary benchmarks: (1) an internal synthetic dataset of 52 curated Python bugs spanning easy/medium tiers, and (2) an OSS repository benchmark using three injected defects in the pallets/click CLI library (v8.3.2), tested across four LLMs. On the synthetic dataset, Qwen 2.5 72B achieves a 57% pass rate (65% easy, 22% medium) at just 32 s average per case. On real OSS bugs, only Gemini 3 Pro resolves one case (33%); all others fail at localization. Compared to a Gemini CLI baseline, our agent delivers 3.1–3.4× token reduction and 2.5–2.7× latency improvement with identical resolution outcomes, confirming that efficiency is architectural while pass rate is a function of model reasoning depth.

9. Analysis: What Drives Performance

Model Reasoning Quality → Pass Rate

The clearest signal across both benchmarks: stronger reasoning models fix more bugs, independent of agent scaffolding. Gemini 3 Pro’s chain-of-thought directly maps the test failure traceback to the injected mutation, resolving in 2 steps. Gemini 3 Flash, with the same scaffolding, burns 10 retries on the same case.

On the synthetic dataset, Qwen 2.5 72B achieves 65% on easy bugs but only 22% on medium — the drop mirrors the reasoning depth required, not the agent architecture.

Agent Design → Efficiency

Efficiency gains over the Gemini CLI baseline are entirely architectural:

  • Targeted tool calls — reads only the relevant function (not full file)
  • Dead-end memory — skips patches already proven to fail
  • Structured retry context — compact diff instead of full traceback resend
  • Planner persona — primes model to emit minimal JSON patch plans

These produce identical resolution outcomes to the baseline while cutting input tokens by 3.1–3.4× and wall time by 2.5–2.7×.

10. Conclusion

Finding 1 — Model quality determines pass rate. Across both benchmarks, the gap between models dwarfs any agent-level optimization. Gemini 3 Pro resolves bugs that Gemini 3 Flash cannot, using the exact same scaffold. No amount of retry logic compensates for insufficient reasoning depth on medium/hard cases.

Finding 2 — Agent design determines efficiency. Our PEC agent achieves 3.1–3.4× input-token reduction and 2.5–2.7× latency improvement over a Gemini CLI baseline, at zero cost to resolution quality. This makes large-scale batch evaluation practical.

Finding 3 — Synthetic ≠ OSS difficulty. 57% pass on the synthetic dataset vs ≤33% on real OSS bugs reveals that large-file localization and multi-module context are the key unsolved challenges.

Future directions: (1) AST-guided patch targeting to eliminate line-offset localization errors; (2) Longer retry budgets with curriculum difficulty scaling; (3) Cross-file retrieval (RAG over repo) for architectural bugs; (4) Hard-tier synthetic cases to bridge the gap with OSS complexity.
